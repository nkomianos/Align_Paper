# Post-result novelty recheck — 9 September 2026

This recheck concerns what our completed evidence actually supports. It is not a literature-exhaustiveness claim or a new experiment.

[Auditing and Decomposing Feedback-Driven Evolution in LLM Test Generation under the Oracle Problem](https://arxiv.org/html/2608.19626v1), submitted August 20, already studies single-reference artifacts, equal-budget resampling, an independent implementation-panel audit, and real versus placebo execution feedback. Its reported cohorts comprise 142 DEV, 114 external and 138 qualification-amended held-out tasks, with explicit limitations on confirmation and semantic panel disagreement. The introduction and oracle definitions distinguish executable agreement from semantic truth. Our one fixed-helper counterexample and metadata parser diagnosis cannot by themselves support a novel generic “verification artifacts mislead evaluation” paper. A contribution would need a distinct mechanism and substantive new evidence, not repackaging the same warning.

[Do LLM Evaluators Prefer Themselves for a Reason?](https://arxiv.org/abs/2504.03846), revised December 2025, separates objectively justified self-preference from harmful self-preference on verifiable tasks across seven model families. Thus a family difference must be separated from capability and output-quality differences. Our observed interface asymmetry is a confound, not evidence for harmful self-preference. This paper concerns evaluator judgments; it does not by itself settle executable specification-only security-test generation.

[SWE-Mutation](https://arxiv.org/abs/2605.22175), ACL 2026 Findings, provides 2,636 mutants from 800 original instances and tests seven models. Its focus already covers weak discriminative generated tests and realistic adversarial mutants. A small new task collection or observation that test generators miss bugs is not sufficient novelty.

The narrow remaining hypothesis is a generator-by-verifier-family interaction on the exact same naturally incomplete security patches, after independently establishing transport validity, useful detection power, task support and comparable budgets. Our current result does not identify that interaction. A verified null on one task is not a valid null for this hypothesis. The new transport prompt and two natural components are preparatory only.

Decision: preserve the current G0 as an inconclusive assay and its parser correction as developmental evidence. Do not pivot to a generic oracle-audit paper merely because the main experiment failed. A new GPU run still requires both an adequate independently sourced task population and a prospectively qualified measurement interface. Current data do not justify an ICLR submission or a high-confidence acceptance claim.
