# Additional primary-source idea screen, September 10

These are literature screens, not independent replications. No paper is qualified.

1. [Privileged, but Biased](https://arxiv.org/html/2608.04794v1), August 5:
   Already measures reference preference using supplied, alternative correct,
   incorrect and unrelated solution targets. Its Appendix E inserts a thinking
   closure before scoring appended targets. A potentially useful question is
   whether such bias measurements predict outcome changes under interventions
   that preserve the open reasoning prefix. The measurement difference itself
   is not novelty, and generic reference-bias diagnosis is occupied. Our frozen
   thinking PMI diagnostic is a prerequisite apparatus check only. A causal study
   still needs valid alternative continuations and held-out problem-level outcomes.

2. [Problem-Space-Guided OPSD](https://arxiv.org/html/2608.01589v1), August 3:
   Already replaces full solutions with structured problem-solving guidance and
   studies relevance and coherent paths. Generic biology/cognition-inspired
   structured-teacher guidance therefore has a close prior. Do not launch an
   interchangeable structured-guidance recipe as a supposedly new paper. Full
   source, compute and split audit remains unperformed.

3. [On-Policy Self-Distillation without Any Supervision](https://arxiv.org/html/2608.06296v1), August 6:
   Already uses self-consistency and short majority-answer traces to supervise
   disagreeing long traces. Generic majority-teacher/minority-student distillation
   is occupied. An untested question is whether it amplifies systematic shared
   errors on matched problems where consensus and truth disagree. This would
   require independent executable truth, matched initial capability, fixed
   compute and a comparison to ordinary self-training. No implementation is
   admitted by this screen; no result or novelty claim follows from the abstract.

4. [ObserverBench](https://arxiv.org/html/2609.03026v1), September 2:
   Already distinguishes effect-prediction accuracy from downstream intervention
   loss, including GPT-2 and Qwen circuit experiments and direct-loss observers.
   A generic decision-aware mechanistic probe is therefore not an untouched idea.
   Only its framing and benign intervention summary were screened here; no
   benchmark replication, security experiment or dataset inspection was performed.

Priority remains a small controlled attribution test rather than another generic
method implementation. The most concrete open candidate is whether apparent
reference-assisted improvement is explained by question-only sharpening or by
reference-specific learning. The exact null example establishes a confound, not
that it dominates actual training. Reject this paper direction if matched controls
explain no practically important held-out difference or existing work already
answers the same causal question. The current 24-question diagnostic cannot
resolve this publication gate.

Further feasibility check for candidate3: CPU replay of the existing16DEVquestion
bank found one wrong-consensus/correct-final-answer minority witness. Raw reasoning
inspection shows that minority used an incorrect area formula that accidentally
produced the right answer; it is not a validated reasoning witness. No consensus
training admitted. See CACHED_CONSENSUS_FEASIBILITY_20260910.md. The u-OPSD paper
also already crosses reference/target length selections (Table4) and reports
roughly72GPUhours for one default training run (AppendixD), excluding evaluation.
Thus neither a simple length-selection ablation nor full default reproduction is
an attractive new project within this budget.

Numerical inference mismatch is also an occupied topic: [Defeating the Training-
Inference Mismatch via FP16](https://arxiv.org/abs/2510.26788) and [Beyond Precision](https://arxiv.org/abs/2602.01826).
Our cached/full apparatus diagnosis is a correction, not a novelty claim.
