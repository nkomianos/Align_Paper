# Shared-seed proposal: application admissibility screen

The user's pasted proposal explicitly requires an application that interprets
coupling causally and transformations that respect its structural assumptions.
The existing binary fixed-marginal demonstration is developmental; expected
returns remain unchanged under marginal-preserving transformations. No frozen
conditional-generator counterfactual study has been run here.

Inspected methods and data/code availability in
[Outputs of generative diffusion models are often unattributable](https://www.nature.com/articles/s41467-026-75667-5).
The authors define a training-data omission/ablation intervention and keep
computational exogenous factors, including diffusion noise, fixed. Their
counterfactual radius compares generated samples under that procedure. Code and
processed measurements are linked from the paper; weights were not inspected.

Independent assessment: an intervention-dependent rotation of the sampling noise
would change an additional input to this specified computational experiment.
Unchanged output marginals would not establish that the new experiment preserves
the authors' intervention. Therefore this paper is not presently an admissible
target for our proposed free latent-rotation stress test. This does not validate
every attribution conclusion or establish counterfactual identification from
marginals generally. It rules out this particular proposed criticism.

Any future application must distinguish a declared computational counterfactual
from an inferred real-world identity correspondence. A sensitivity analysis must
state which structural assumptions it preserves. No GPU launch follows from
finding visually different paired images; no new theorem is claimed.
