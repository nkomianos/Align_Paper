# Memory Graft security S4 early-MLP intersection pre-registration

## Motivation and registered estimands

S3 found, with exact full replay, that restoring all MLP parameters and restoring
all parameters in layers 0--5 each removed the learned mapping at both Pythia
sizes. Those interventions overlap but do not identify their intersection. S4
therefore tests exactly one prospectively selected group: MLP parameters in
decoder layers 0--5. This selection is a follow-up generated by S3 and is not
presented as independent confirmation of an unselected hypothesis.

For all five sealed S1 seeds at Pythia-410M and Pythia-1.4B, first restore the
complete graft to the seed-matched clean state. The primary estimand is
necessity: intact poisoned ASR minus ASR after restoring the early-MLP group to
clean. The secondary estimand is sufficiency: ASR after transplanting the
poisoned early-MLP group into the clean backbone minus clean ASR. These are
reported separately; neither is a gate for the other and there is no cross-size
AND gate.

## Derived thresholds

The downstream localization claim asks whether a parameter group accounts for
an effect large enough to matter to the deletion assay. S1 fixed 0.15 ASR as the
minimum effect the assay must resolve. S4 therefore uses the same scientific
scale: necessity passes within a size only when the lower endpoint of the
five-seed two-sided 95% Student-t interval exceeds 0.15. Sufficiency uses the
same derived threshold because a transplanted group must install at least the
same detectable ASR effect to support a self-contained-storage claim. It is a
separate secondary reading, not a conjunct.

Clean and poisoned no-ops must reproduce exactly. Complete-backbone transplant
and restoration must each retain a lower 95% effect endpoint above 0.15. These
are apparatus-validity controls: failure would mean checkpoint patching cannot
express the already established S2 contrast, so S4 component readings would be
invalid rather than negative.

## Fixed data, checkpoints, and scale

Use the unchanged 1,024 held-out 64-token contexts, one-token exact argmax
scoring, fixed trigger/payload, sealed S1 checkpoints, model revisions, hash
bank, and all five training seeds at both sizes. The seed is the replication
unit; prompt rows are retained but never treated as replicates. No training or
checkpoint selection occurs in S4.

Runner plus full replay is projected at 0.5 GPU-hours, 1.14% of the estimated
43.9 hours remaining. The scale is justified by testing the only intersection
licensed by S3 across all ten independent trained checkpoints, with the same
1,024-prompt resolution as the parent assay. Adding prompt rows would not add
independent optimizer outcomes.
