# Independent Hindsight theory and literature audit

Audit date: 5 September 2026 UTC / 4 September 2026 Pacific. This note is an append-only correction to the prior record. The complete mandated handover was read before repository inspection. No GPU, model inference, new experiment, remote host, or locked confirmation was used. Existing scientific artifacts were not modified.

## Decision

**Preserve the persistence-identification question, pivot the experiment and paper framing, and do not launch the existing queue unchanged.** The restricted expression/transition construction is mathematically sound, but it does not establish general personalized-policy regret or a neural learning failure. The strongest finite-state correction is a standard difference estimator. One advertised robustness policy comparison omits a stronger simple baseline already present in the raw evidence. A paper specifically validating delayed persistence measurements remains a possibility, not a submission-ready result. A generic measurement or likelihood-versus-utility fallback is already occupied by close primary work discussed below.

The narrow thesis worth testing is: *For a declared delayed preference objective, immediate next-turn feedback can be an unidentified proxy; a small, independently validated delayed measurement sample can improve learning if the proxy contains useful information beyond the same delayed labels alone.* Its empirical parts remain unproved.

For T1 an exact counterexample needs only one old log: deploy action 1 iff that log's `Z0=0`, otherwise deploy action 0. This is a deterministic rule. Under both worlds `P(Z0=0)=.4`, so the two expected regrets are `.2*.6=.12` and `.4*.4=.16`. Worst-case expected regret `.16` contradicts the literal `.2` learner claim. It does not contradict the correctly scoped randomized minimax `2/15` bound.

The theorem's declared utility is contemporaneous post-action persistent-state matching. It can prefer an action because it changes the persistent preference to match itself. A pre-action-fidelity or consent-based objective is a different estimand and need not rank the worlds oppositely. The paper must choose and defend its objective before interpreting a correction as beneficial.

## Strongest objection and decisive design requirement

The strongest objection is: *You chose two latent interpretations of identical logs, supplied an oracle that reveals which interpretation is true, and improved a familiar surrogate with standard residual correction. Why does this tell us anything useful about real interaction learning?*

A decisive revised experiment must answer that objection with a qualified learner and genuinely held-out task clusters whose preferred semantic direction varies. Give raw SDPO, official selective feedback, ordinary same-anchor SFT/SDPO, a state/memory or pooled simple estimator, and the correction exactly matched delayed-label access and declared compute budgets. Include clean truthful feedback, expression-only change, persistent change, and independently varied measurement contamination. An action-stratified baseline must exploit any action for which immediate and delayed labels coincide. Keep a full-delayed oracle as a diagnostic ceiling for teacher imitation while scoring **actual declared utility separately**; the best utility policy need not mimic the oracle's probability calibration.

The first cheap neural check should establish teacher semantic calibration, format validity, sign of improvement in declared semantic utility, and whether the abundant immediate signal reduces equal-label estimation error after simple stratification/shrinkage. A whole-vocabulary gradient cosine threshold can be dominated by shared format tokens. Failure of that cosine alone should not be called failure of causal identifiability. A qualifying result justifies policy learning; it does not establish real human influence. Freeze new criteria before observing any capable-model endpoint and preserve the superseded protocol.

An independent human substrate is useful only if it measures the same pre/post or delayed construct under an auditable intervention. A capable reader on observational PUPPET/ThoughtTrace data is a measurement/capability study, not causal validation of preference influence. A natural language task surface derived from PAHF does not itself make the state transition empirical.
