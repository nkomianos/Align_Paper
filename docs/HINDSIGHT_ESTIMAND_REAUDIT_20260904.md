# Hindsight idea: return to the actual estimand

## Existing evidence is not a thesis test

The journal already records an elementary observational-equivalence construction,
CPU sparse-anchor estimation, a negative prompt-correction assay, and learner
qualification failures. It also records counterexamples to automatic polarization:
the Bayesian symmetric channel restores balance and a simple population model is
not unstable. Do not promise the originally proposed polarized fixed point.
The completed single-profile calibration added no trained-policy result.

The target remains whether downstream agreement can reward policy-induced change
rather than satisfaction of an independently specified preference objective.
Punctuation compliance is neither a preference transition nor a substitute for
this estimand. Stop treating an arbitrary formatting learner as the decisive gate.

## New external-data constraint

Talk2AI's published schema has pre-session trust/personality/cognition scales and
post-session questions about conviction, perceived opinion change, humanness, and
hypothetical donation. Those are not matched independent pre/post measurements of
the same underlying topic preference. A post-session statement about initial
conviction is still post-treatment. The conversation's first message may provide
a linguistic baseline, but scoring it adds measurement assumptions.

Therefore, use this dataset only for a clearly labeled observational association
or measurement study; it cannot by itself identify satisfaction versus influence
or validate Anchor-SDPO causally. Existing longitudinal analyses must also be
checked for overlap before claiming that analysis as new. No participant records
were downloaded in this audit.

## New mandatory baseline

SLIFT (August 10, 2026) separates feedback components into task fixes, conditional
specifications, and components with no reliable positive update. It uses generalist
and specialist adapters and evaluates on MemoryBench/WildFB. Generic selective
feedback learning is therefore not our novelty. A causal method must show what
remains unidentified after such task-relative filtering, rather than compare
only against unfiltered adaptation.

Primary source: https://arxiv.org/abs/2608.09109 . This is an abstract-level
baseline identification; the full method/code still requires detailed review.

## Decision and next discriminating work

Do not call the original idea disproved. Do not call it ready for a paper either.
The next useful theoretical test is a fully specified small interaction model
with (a) a defined anchor objective, (b) an actual update rule, and (c) a regime
where the update improves valid correction under zero influence. Only then test
whether the same update sacrifices that objective under influence. Include the
previously observed stable cases instead of designing them away. A counterexample
alone is insufficient; characterize the conditions and compare a corrective rule.

This must improve on the existing elementary construction, not repackage it.
If it cannot produce a substantive result beyond known dynamic-preference theory,
park the causal-paper version without spending another GPU on proxy tasks.
